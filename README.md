# QR-SENA 🚀

Sistema de gestión de asistencia mediante códigos QR, diseñado para instructores y aprendices.

## ✨ Características
- **Dashboard en tiempo real**: Visualización de estadísticas de asistencia.
- **Toma de asistencia QR**: Generación de códigos dinámicos por ficha.
- **Gestión de Alertas**: Notificaciones automáticas de inasistencias críticas.
- **Mis Fichas**: Administración de grupos y aprendices.
- **Reportes**: Visualización histórica de registros.

## 🛠️ Tecnologías
- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- **Backend**: Node.js, Express.
- **Iconos**: Lucide Icons.
- **Base de Datos**: Archivos JSON (Persistencia local).

## 🚀 Instalación
1. Clona el repositorio.
2. Ejecuta `npm install` para instalar las dependencias.
3. Inicia el servidor con `npm start` o `node server.js`.
4. Abre `http://localhost:3000` en tu navegador.
